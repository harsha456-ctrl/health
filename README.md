# Heart Failure Clinical Records — Machine Learning Project

## Dataset
UCI Heart Failure Clinical Records, Dataset 519:
https://archive.ics.uci.edu/dataset/519/heart+failure+clinical+records

## Contents
- `Project_Report_final(1).html` — project report
- `docs/README.md` — submission guide
- `requirements.txt` — Python dependencies
- `src/train.py` — reproducible training/evaluation code
- `results/published_benchmark.csv` — published benchmark values

## Reported experimental results in the submitted report
The report contains 5-fold stratified cross-validation results for Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, SVM, LightGBM, MLP, Extra Trees and related configurations, together with accuracy, MCC, recall, specificity, F1-score, ROC-AUC and latency where available.

## Reference
Chicco, D. & Jurman, G. (2020), BMC Medical Informatics and Decision Making, 20:16.
